# Dogfood design and setup refinement

## Rendered review

The board answers: what is working, what needs me, and what is ready for review?
Its primary action is New request. Overview answers whether the project works; Plan
identifies the next outcome and its proof. Preserve those jobs and the existing stack.

The three highest-impact adjustments from the actual board, conversation, overview,
plan and page-report review are:

1. Lighten the heavy gray navigation and lane surfaces so actual work carries the screen.
2. Improve title, context and control hierarchy, and constrain long conversation lines.
3. Give the product a recognizable original mark that reads at navigation and favicon size.

Preserve the native system typography, restrained blue actions, semantic status colors,
real counters and evidence. Empty states explain the next step without invented progress.
Mobile retains the selected conversation before the queue.

## Direction

Use the app-screen method's framed-sheet idea as a restrained surface system, adapted to
Dogfood's existing shell, not a new framework or marketing layout. Keep system type and
the functional blue palette. One quiet edge separates navigation from the working surface.
Controls and cards share spacing and shape; color describes actions and actual state.

Ali selected logo direction **1**: a front-facing dog with folded ears, white on a flat blue
tile. Use the selected vector consistently for the sidebar, favicon, first run, README and
brand guide. No mascot illustrations or decorative gradients are added to the application.

## Wiring

The CLI, MCP and board must invoke the same registered-project operations. Native agent
availability, account sign-in and a reachable dispatcher are separate checks. Doctor must
report what it actually observed, and missing optional AI-review credentials must not
prevent local planning. Setup may sync the maintained skill and stable local executable
paths, preserving existing custom configuration and credentials.

meaning and the existing acceptance boundaries. Exercise CLI requests/comments/actions,
